# Controle de Suspensões de Inscrições

Plugin administrativo para Moodle 4.4 e 4.5.

## Recursos

- Pesquisa AJAX e seleção de vários alunos.
- Seleção de disciplinas específicas ou de todas as disciplinas atuais.
- Suspensão permanente de inscrições por meio da API de inscrições do Moodle.
- Motivo obrigatório, revisão e confirmação.
- Histórico auditável e reativação em lote.
- Importação CSV/TXT por nome de usuário, e-mail ou matrícula.
- Atalho na navegação de cada disciplina.

## Instalação

Instale o ZIP em Administração do site > Plugins > Instalar plugins.

## Aviso

Teste primeiro em ambiente de homologação. Métodos de inscrição personalizados podem implementar regras próprias.
